Mobile Development

With over 3 years of hands-on experience, I specialize in building high-performance, cross-platform mobile applications using Flutter and Dart. My expertise spans the full mobile development lifecycle — from UI/UX implementation to backend integration.

  • Flutter & Dart — Pixel-perfect UIs, custom widgets, complex animations, and platform-specific integrations for both iOS and Android.
  • Firebase — Authentication, Firestore, Cloud Functions, push notifications, and real-time data synchronization.
  • REST APIs — Consuming and integrating third-party APIs, building data layers with Dio/HTTP, and handling complex JSON serialization.
  • State Management — Proficient with Riverpod, Provider, BLoC, and GetX for scalable, maintainable app architecture.

Frontend Development

I craft responsive, accessible, and visually polished web interfaces. From semantic HTML to modern JavaScript frameworks, I deliver frontend experiences that are fast, beautiful, and user-friendly.

  • HTML & CSS — Semantic markup, Flexbox, CSS Grid, custom properties, animations, and modern layout techniques for fully responsive designs.

Backend Development

I design and build robust server-side architectures that power reliable, scalable applications. From RESTful API design to database management, I handle the full backend stack.

  • Node.js — Express.js APIs, real-time WebSocket servers, middleware patterns, and npm package management.

UI/UX Design

I create intuitive, user-centered designs that balance aesthetics with usability. From initial research and wireframes to polished, production-ready prototypes, I ensure every interface is thoughtful, accessible, and visually engaging.

  • Figma — End-to-end design workflows including component libraries, auto-layout, interactive prototypes, and developer handoff.
  • Wireframing & Prototyping — Low-fidelity sketches to high-fidelity clickable prototypes for rapid iteration and stakeholder feedback.
  • User Research — User interviews, personas, journey mapping, and usability testing to validate design decisions with real data.
  • Design Systems — Building scalable design tokens, reusable component libraries, and style guides that ensure consistency across products.

AI Automation

I design AI-assisted workflows around a real operational problem, then keep deterministic rules and human approval where the system needs accountability.

  • Workflow design - Map inputs, exceptions, owners, approval points, and a measurable outcome before choosing a model or tool.
  • Structured outputs - Validate AI responses with schemas and deterministic business logic instead of parsing free-form prose.
  • Human review - Keep customer-facing messages, commercial decisions, and sensitive updates behind a named reviewer.
  • Testing and observability - Cover normal cases, missing data, provider failures, and handoffs before real work depends on the workflow.
